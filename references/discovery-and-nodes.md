# 只读发现、VPS 与出口选择

## 必须重新发现的事实

记录 OS、架构、客户端与核心版本、真实进程路径/UID、配置目录、服务模式、API socket/端口、监听端口、系统网络服务名称、默认路由、TUN 接口、DNS 与当前代理环境变量是否存在。只输出环境变量的名称或脱敏端点，不打印 token、密码或完整订阅。

macOS 可读证据：`ps -ax -o pid=,uid=,comm=`、`lsof`、`ifconfig`、`netstat -rn`、`route -n get`、`scutil --dns`、`scutil --proxy`、`networksetup -listallnetworkservices`、相应 get 命令、launchd 状态。避免打印完整进程参数，它们可能带凭据。命令受限或需要管理员时记为未取得，不凭 exit 0 推断输出有效。

配置路径和 API 地址从当前安装推导，不固化用户名、UID、`utunN` 或 7897。客户端可能因占用而临时换端口；用运行时 API、PID 和真实监听交叉验证。

若已存在其他代理、抓包器、VPN、端点防护或 Tailscale 的 `100.100.100.100` DNS，报告其对当前需求的实际影响，保留用户已批准的处理方式。此技能不枚举或补写组织域名，也不自动放行组织专属公网形式路由。

## 一次收齐选择

首次改动前提供：

- **A 单海外节点**：列出真实节点的客户端测速结果、延迟、协议和可用性；过滤“剩余流量、到期时间、官网”等信息条目。地区按实际出口查询，不能只信节点名称。Claude 可用地区使用服务方当前官方列表核验。
- **B 住宅 SOCKS5 经跳板**：住宅 IP/域名、端口、账号、密码只通过安全本地输入收集；列出可用跳板，保留用户选定的其他可用节点供手动切换。
- **改动范围**：哪些覆写、服务、自启、DNS、防火墙和自动切换会变；明确哪些需要用户在 Terminal 输入管理员密码。

不要为已批准的相同范围重复询问。用户只给 IP、SSH 端口和 root 登录方式，意味着可以准备服务器接入流程，不能要求把 root 密码贴入对话。

## 只有 VPS 时

受支持系统使用 [VPS 自动接入](vps-automation.md) 的实际脚本与桌面导入接口，下面是选择及安全边界；不要停留在口头指导或另起一套临时安装器。

1. 让用户在本机交互式 SSH 会话输入密码/私钥口令；核对 SSH 主机指纹。不得绕过主机密钥异常，也不得从钥匙串取密码。
2. 读 OS/架构、现有服务/端口、磁盘、服务管理器和主机防火墙。保留 SSH 和已有业务；不要把一次新建代理升级成整机重装或系统加固。
3. 依据所有目标客户端实际支持情况选协议。Shadowsocks 2022、VLESS 等都不是无条件默认；客户端和服务端的 UDP/UOT 版本必须匹配。
4. 从项目官方 release/安装源获取软件，固定版本，检查可用的签名或校验和；不要直接执行不可审查的远程 `curl | sh`。
5. 在服务器备份相关配置、服务单元及防火墙差异；生成强随机凭据到仅用户/root 可读文件，不在日志回显。只开放已选 TCP/UDP 端口，不创建无认证开放代理。
6. 服务端验证配置与监听，再从客户端测速并验证实际出站。检查跨设备协议兼容、UDP 支持和地域，而不是只测 SSH/ping。
7. 交付服务启停/更新/恢复路径。节点分享 URI 和二维码均按凭据处理；不要上传第三方二维码或订阅转换站。

## 出口结构

A：`海外出口 (select) → 已测通节点`。不含 DIRECT；检测失败只报告，不改为自动切换。切换前先走客户端节点测速接口确认可用。

B：`海外出口 (select) → 住宅 SOCKS5 → 跳板 (select) → 可用中转节点`。Mihomo 可用受版本支持的 `dialer-proxy` 表达拨号链；其他客户端用其原生能力。住宅代理的地址必须经跳板，不能最终命中住宅代理自身形成循环。住宅 SOCKS5 的 UDP 按该需求关闭，不能以 DIRECT 补足 UDP。住宅组里只放住宅节点，跳板组保留获准的候选节点。

失败边界：客户端不支持链式或所需认证方式就标“未实现”，不能导出看似正确但实际忽略字段的配置。

实施时核对客户端、核心的当前官方文档及 Claude 支持地区，不预置参考网址。
